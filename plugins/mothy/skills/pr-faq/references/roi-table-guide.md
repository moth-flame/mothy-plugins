# ROI Table Guide — the house standard

The Predictive Readiness Analytics PR/FAQ (see exemplar-predictive-readiness.md) sets the
bar for the "What ROI can customers expect?" FAQ. Reproduce that shape:

## Structure

1. **Summary table** — one row per organization size tier. Columns: Org Size, [Cost
   Reduction category 1], [Cost Reduction category 2], Price Point, Total Spend, % ROI.
   Every large number in the table carries a superscript source number.
2. **Detailed Breakdown of Calculations** — for each column, show the arithmetic in full:
   per-unit cost × incidence rate = total, then the ROI formula
   ((Total Benefits − Total Spend) / Total Spend) × 100.
3. **Numbered source list** — live URLs, one per claim. Government and academic sources
   preferred (APA, NIH/NCBI, DoD comptroller, service-branch reporting, VA reports).

## Rules

- Every figure that isn't the customer's own price point must have a numbered, citable,
  live source. Web-research these; do not reuse the exemplar's numbers for a new product.
- Re-verify the arithmetic before delivering (compute it, don't eyeball it).
- Price-point assumptions are confirmed with the human — they are strategy, not research.
- Round honestly and state incidence-rate assumptions inline so a skeptical customer can
  audit the model.
- If the evidence is thin, say so in the answer rather than manufacturing precision — an
  ROI range with stated assumptions beats a fake-precise single number.
